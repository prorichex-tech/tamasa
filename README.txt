TAMASA MEBEL — САЙТ С ВСТРОЕННЫМ РЕДАКТОРОМ

СТРУКТУРА
- index.html — главная страница в утверждённом дизайне.
- style.css / script.js — стили и обычная интерактивность сайта.
- catalog/kukhni/, catalog/stoly/, catalog/shkafy/ — страницы каталогов.
- login.php — отдельная страница входа в фирменном дизайне.
- api.php — авторизация, сессия, сохранение текста и изображений.
- editor.js / editor.css — встроенные инструменты редактирования на публичных страницах.
- create-admin.php и create-admin.ps1 — создание учётной записи через PHP CLI.
- storage/ — закрытые данные администраторов и контента.
- uploads/ — загруженные фотографии.

КАК РАБОТАЕТ РЕДАКТОР
1. На сайте в футере есть малозаметная ссылка «Вход».
2. Сотрудник открывает login.php и вводит выданные логин и пароль.
3. После успешного входа сотрудник возвращается на обычную главную страницу.
4. На самом сайте появляются небольшие кнопки редактирования рядом с поддерживаемыми текстами и изображениями.
5. В каталогах можно изменить название, описание и цену карточки, заменить фото, добавить новую карточку или удалить существующую.
6. Изменения сохраняются на сервере и остаются после перезагрузки.
Отдельной панели управления и переключателя «режим редактора» нет. Доступ определяется серверной сессией. Сессия заканчивается по истечении срока действия или закрытию браузера в зависимости от настроек PHP.

СОЗДАНИЕ АДМИНИСТРАТОРА
Откройте PowerShell в корневой папке сайта, где лежит create-admin.ps1, и выполните:
  .\create-admin.ps1
Введите логин (3–40 латинских символов) и пароль (не менее 12 символов).
Если PowerShell блокирует скрипт:
  powershell -ExecutionPolicy Bypass -File .\create-admin.ps1
Требуется PHP CLI в PATH. Пароль хранится только в виде хеша password_hash().
Публичной регистрации нет.

ЛОКАЛЬНЫЙ ЗАПУСК
Из корневой папки проекта:
  php -S localhost:8000
Откройте:
  http://localhost:8000
  http://localhost:8000/login.php
Окно PowerShell с сервером должно оставаться открытым. Двойной клик по index.html не подходит: PHP API и сессии требуют веб-сервер.

ФОТОГРАФИИ
Поддерживаются JPG, PNG и WebP до 12 МБ. Изображение сохраняется в uploads/ и выводится с обрезкой по размеру визуального блока сайта (cover). Серверная перекодировка/ресайз не выполняется, расширение GD не требуется. Для оптимальной скорости заранее используйте квадратные изображения около 1200×1200 px.

ВАЖНО ДЛЯ ХОСТИНГА
- Размещайте содержимое папки TAMASA_MEBEL_complete_redesign в корне сайта либо корректно настройте пути при размещении в подпапке.
- Нужен хостинг с PHP 8.1+ и разрешёнными сессиями, загрузкой файлов и записью в storage/ и uploads/.
- Убедитесь, что storage/ недоступна из браузера. В архиве есть .htaccess для Apache; для Nginx/IIS настройте запрет доступа к storage/ отдельно.
- В uploads/ запрещено выполнение PHP-файлов; правило .htaccess рассчитано на Apache. Для Nginx/IIS настройте запрет исполнения скриптов в uploads/.
- Локальный сервер php -S предназначен только для тестирования, не для публичного размещения.
- Обязательно используйте HTTPS на реальном домене.
- Перед публикацией проверьте права на папки storage/ и uploads/.

ПУБЛИКАЦИЯ И КОНТЕНТ
- Добавить номер WhatsApp в CONFIG.whatsapp в script.js и НОМЕР_WHATSAPP в catalog/catalog.js.
- Заменить временные заглушки реальными фотографиями, текстами и ценами.
- Заполнить юридические сведения в футере и проверить политику персональных данных.
- Проверить контакты, ссылки, мобильные разрешения и все формы.
- Каталожные цены 0 ₸ — временные заглушки, а не предложение изготовить мебель бесплатно.
